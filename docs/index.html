What's evaluated

1,624 unique cards tracked from CHL tournament decklists — 39 currently pointed, 1,585 unlabeled. The model is two-stage: a classifier (should this card be pointed at all?) trained on all cards, and a regressor (how many points?) trained only on pointed cards.
